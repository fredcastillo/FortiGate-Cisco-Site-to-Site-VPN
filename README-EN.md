# FortiGate–Cisco Site-to-Site IPsec VPN Lab

This repository documents the GNS3 Security Networks lab implementing a Site-to-Site IPsec VPN between a Cisco 7200 and a FortiGate.

The topology uses a Cisco 7200 as one IPsec peer and a FortiGate as the other peer. The user network is `10.21.75.0/25`, the server network is `10.21.75.128/28`, and the WAN peers are `203.0.113.21` and `203.0.113.26`.

The Spanish README contains the complete technical documentation and evidence index.
