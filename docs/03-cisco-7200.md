# 03 — Cisco 7200

## Sistema

- Plataforma: Cisco 7200
- IOS: 15.2(4)S6
- Hostname: `R1-CISCO-VPN`

## Interfaces

### Gi1/0 — WAN

`203.0.113.21/30`

- NAT outside
- Crypto map `FGT-VPN-MAP`

### Gi2/0 — LAN

`10.21.75.1/25`

- NAT inside
- Gateway de VLAN 10

## DHCP

Pool: `VLAN10-USERS`

- Network: `10.21.75.0/25`
- Default router: `10.21.75.1`
- DNS: `8.8.8.8`
- Exclusiones: `.1–.9`, `.101–.126`

## NAT

La ACL `NAT-USERS` excluye el tráfico hacia `10.21.75.128/28` y permite el resto de la red de usuarios para PAT sobre Gi1/0.

## IKEv2

- Proposal: `FGT-IKEV2-PROPOSAL`
- DES
- SHA256
- DH14
- PSK
- Keyring: `FGT-KEYRING`
- Peer: `203.0.113.26`

## IPsec

- Transform set: `FGT-IPSEC-SET`
- `esp-des esp-sha256-hmac`
- Tunnel mode
- PFS Group14
- Crypto map: `FGT-VPN-MAP`
- Protected traffic: `10.21.75.0/25 ↔ 10.21.75.128/28`
